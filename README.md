# istanbul-care-pages

Next.js 14 (App Router) site with four pages styled to match the Istanbul Care Hair Clinic brand:

- `/tools` — Hair transplant tools as cards
- `/review` — Before / after operation cards with patient reviews
- `/hair-transplant` — Hub listing DHI, FUE, Sapphire FUE and other techniques
- `/blog` — Article listing with categories, dates and reading time

Brand colors: `--color-primary: #164b6a`, `--color-secondary: #41758c`, `--color-accent: #22c55e`.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

This project is deployed to Vercel.
